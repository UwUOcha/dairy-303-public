# Граница публикации

Публикуется отдельное дерево исходников универсальной платформы, созданное
`make export-platform`. Текущий репозиторий установки и его историю Git открывать
для этого не требуется. Экспорт ничего не отправляет на GitHub и не меняет сервер.

| Публичная платформа | Закрытая установка |
| --- | --- |
| `raspd`, `botd`, `webd`, встроенная админка | Реализация вузовского адаптера и особенности исходного API |
| `pkg/provider`, OpenAPI, проверка адаптера | Доступ к API вуза, служебные токены, токены ботов |
| Универсальная схема, миграции, импорт, синхронизация, UI | Базы пользователей, сессий, ключей, истории и резервные копии |
| Профиль вымышленного вуза, Python-пример адаптера | Рабочий профиль с ID операторов, доменами и локальными путями |
| Общие Compose, Dockerfile, systemd и env-примеры | Рабочие env, proxy, IP-списки, скрипты переключения и отката |
| Тесты, публичный CI и ручной выпуск платформы, руководства | Отчёты о сервере, исследования источника и архивы установки |

Профиль сам по себе не секрет: название, часовой пояс, цвета и ссылки сайта
должны быть видны пользователям. Но рабочий файл целиком не является публичным
примером: в нём также могут быть административные ID и пути. Сайт выдаёт только
разрешённые поля профиля. Адаптер также можно выпустить отдельно в будущем,
но он не входит в текущую границу публикации платформы.

## Подготовка дерева

```sh
make export-platform OUTPUT=dist/platform MODULE=example.org/university/schedule
make -C dist/platform all
(cd dist/platform && go test -race ./...)
```

`example.org/university/schedule` — пример. Перед публичным выпуском укажите путь
выбранного Go-репозитория: `MODULE` заменяет объявление модуля и его внутренние
импорты в копии, сохраняя исходный репозиторий. Без `MODULE` путь остаётся прежним.
Каталог назначения должен находиться в `dist/` или вне дерева исходников.

Для повторного экспорта без создания очередной копии:

```sh
make export-platform OUTPUT=dist/platform REPLACE=1 MODULE=example.org/university/schedule
```

Замена разрешена только для результата этого экспортёра с неизменёнными файлами.
Маркер `.platform-export.json` содержит их SHA-256. Ручные изменения, новые файлы,
результаты сборки и `.git` блокируют замену: сохраните нужные изменения отдельно,
а сгенерированные бинарники удалите через `make -C dist/platform clean`.
Старые экспорты без маркера автоматически не удаляются. Символические ссылки
в публичных исходниках и каталоге назначения отклоняются.

Публичный репозиторий — `UwUOcha/dairy-303-public`, Go-модуль —
`github.com/UwUOcha/dairy-303-public`. История создаётся отдельно от закрытой установки.
Платформа лицензирована под **AGPL-3.0-only**, общая библиотека `pkg/provider` —
под **MIT**. Учебный Python-адаптер — часть платформы под AGPL. Тексты и границы
лицензирования находятся в [LICENSING.md](../LICENSING.md).

В публичном репозитории CI проверяет push и PR; ручной workflow `release`
выпускает версию с исходным архивом, контрольными суммами и образом в GHCR.
Публикация версии не запускает деплой какой-либо установки.
