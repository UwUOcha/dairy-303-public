# Независимый пример адаптера

Сервис на Python 3 использует только стандартную библиотеку. Он не импортирует
Go-код ядра или других адаптеров. В `data.json` находятся вымышленные справочники и
недельный шаблон занятий; сервис разворачивает его в даты запрошенного диапазона.

```sh
python3 examples/adapter-json/server.py
# В другом терминале из корня репозитория:
PROVIDER_URL=http://127.0.0.1:8310 make check-adapter
```

Настройки: `ADAPTER_HOST` (по умолчанию `127.0.0.1`), `ADAPTER_PORT` (`8310`),
`ADAPTER_DATA` (путь к своему JSON), `ADAPTER_TOKEN` (необязательный Bearer-токен).
В контейнере сервис слушает `0.0.0.0`; порт доступен только внутри сети Compose.

Для нового вуза замените получение и преобразование данных, сохранив
[HTTP-контракт](../../docs/ADAPTERS.md). Пример возвращает свежий `fetched_at`,
поскольку читает локальный источник на каждом запросе. При кэшировании реального
API сохраняйте время получения данных, а не время очередного чтения кэша.
Не возвращайте `complete: true` при ошибке или неполной загрузке источника.
